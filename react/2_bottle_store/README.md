# Bottle Shop

A simple Bottle Shop web application built with React and Tailwind CSS.

## Features

* View all bottles
* Add bottles to cart
* Prevent duplicate items
* View cart item count
* Remove items from cart
* Responsive design
* React Router navigation

## Technologies

* React.js
* React Router
* Tailwind CSS
* JavaScript
